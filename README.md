# QR Generator

A fast, lightweight, and privacy-friendly QR Code Generator that runs entirely in your browser.

## 🚀 Live Demo

https://wbcutter.github.io/QR/

## ✨ Features

- Generate QR codes instantly
- Support URLs, text, phone numbers, emails, and custom content
- Real-time QR preview
- Download generated QR codes
- Mobile-friendly interface
- No account required
- Fully client-side processing
- Fast and lightweight

## 🔒 Privacy

All QR codes are generated locally in your browser.

No data is uploaded, stored, tracked, or sent to any server.

## 📖 How to Use

1. Enter text, URL, email, phone number, or any content.
2. Click **Generate QR**.
3. Preview the QR code instantly.
4. Download the generated image.
